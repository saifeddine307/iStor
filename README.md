# iStor
A modern, responsive, and minimalist e-commerce storefront for Apple products built with pure HTML5, CSS3, and JavaScript.

## ✨ Features
- 📱 Responsive layout optimized for desktop and mobile devices.
- 🎨 Modern UI featuring custom CSS Gradients, Flexbox, and CSS Grid.
- 🏷️ Dynamic category filtering and product grid presentation.
- 🛒 Interactive Shopping Cart badge updates.

## 🛠️ Tech Stack
- **HTML5**: Semantic markup layout.
- **CSS3**: Custom variables, Flexbox, CSS Grid, animations, and media queries.
- **JavaScript (ES6)**: DOM manipulation and dynamic interactivity.
